# ImgOrigin plugin (Cursor Marketplace / Grok Bot)

Connects the hosted ImgOrigin MCP server (`https://imgorigin.com/mcp`). Sign-in is OAuth: install, click Connect, approve once. No API keys.

Tools: `check_listing` (are this listing's photos on other sites?) and `search_image` (where does this photo appear?).
